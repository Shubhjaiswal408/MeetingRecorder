Installation Steps

  1. Connect your XIAO ESP32-S3 Sense via USB.
  2. Open Google Chrome or Microsoft Edge.
  3. Click the Flash Firmware button.
  4. Select the serial port of your board.
  5. Allow the browser to access the device.
  6. Wait until flashing completes.
  7. The device will reboot automatically.

Troubleshooting

  • Device not detected → Try another USB cable.
  • Port missing → Install CP210x USB drivers.
  • Failed to connect → Enter bootloader mode.
  • Manifest download error → Verify file paths.
  • GitHub Pages 404 → Check repository deployment.

Browser Compatibility

  • Google Chrome (Recommended)
  • Microsoft Edge
  • Latest Chromium-based browsers

Safari and Firefox do not support Web Serial API required by ESP Web Tools.
